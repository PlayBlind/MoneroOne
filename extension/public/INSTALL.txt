MONERO MOBILE 0.2.5 — STANDALONE CHROME WALLET

Mainnet is enabled. No independent security audit has been completed.
No phone app, desktop wallet, wallet RPC server, or account is needed.
Network syncing and sending still require a Monero daemon.

INSTALL
1. Extract this archive into a folder you will keep.
2. Open chrome://extensions in Chrome 120 or later.
3. Turn on Developer mode.
4. Click Load unpacked and choose the folder containing manifest.json.
5. Pin Monero Mobile, then click its toolbar icon to open the wallet tab.
6. Create a Mainnet wallet. The default node is https://xmr.triplebit.org.
7. Approve Chrome's request for access to the node you chose.
8. Back up the recovery phrase AND restore height. Scanning starts automatically;
   use Sync wallet at any time to scan immediately.
9. Verify Mainnet and "You're up to date" before receiving or sending XMR.

UPDATING AN EXISTING INSTALLATION
Do not uninstall the old extension if it holds a wallet.
Export an encrypted backup and record your recovery phrase first.
Replace the files in the SAME folder that Chrome already loaded, then click
Reload on chrome://extensions. Loading a different folder can create a new
extension identity with separate wallet storage.
Existing stagenet wallets remain stagenet. Create a separate mainnet wallet;
never try to send real XMR to a stagenet address.

Keep this tab open while syncing or sending.
The web development preview has separate storage from the installed extension.
Do not enter an existing real-funds recovery phrase into a preview.

BACKUP
Write the 25-word recovery phrase on paper and keep it private.
Anyone with these words can spend your Monero.
An encrypted file backup also requires your wallet password.
Removing this extension or clearing browser data may erase local wallets.

VALIDATION AND LIMITS
Real Chrome extension tests passed mainnet creation and live block scanning
against Triplebit and Nodely, including actual Chrome host permission prompts.
The wallet rejects a live stagenet node when configured for mainnet.
Signing, fees, explicit broadcast, receipt and unlocking passed against a real
Monero daemon on an isolated regression network, with valueless test funds.
No real mainnet funds have been received or spent in these tests.
There has been no independent security audit. Do not keep significant funds here.
